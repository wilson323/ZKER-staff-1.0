# 员工市场：数字员工、技能、工具的复制与使用

版本：v2.2｜2026-09-11｜本轮核对源码 7fe65123c8dee1bb2a5542327bcdc6b80e1f7454  
用户确认的产品要求：**员工侧也有市场，可按权限查看并直接复制使用数字员工、技能和工具。**

这是现有 AG/SK/CN/NC/AD 等需求的细化，保持原153项编号和21个领域；新增跨资源页面组P22、流程F13、接口组A17，以及MC-01–MC-10细化验收，不额外创建一套资产、权限或运行系统。

## 1. 员工的完整使用路径

工作区/本次配置 → 资源市场 → 按数字员工/技能/工具筛选 → 阅读用途、输入输出、版本、依赖与可用范围 → 复制并使用 → 我的资源 → 本人节点有效配置 → 原有执行/上下文/交付链。

拥有市场浏览权的员工在“我的工作”页面有市场快捷入口，节点配置候选器也有“从市场添加”。完整应用的入口仍使用既有能力/广场权限槽位，不因为增加一个显式快捷入口就新建平台角色或扩大菜单权限。市场不是仅供管理员查看的后台页面。

满足现有发布、复制、使用和依赖要求的资源走直接成功路径。缺少条件时说明具体原因和恢复入口；已经拥有的权限不重复申请。复制并配置不自动运行，更不直接推动业务节点完成。

## 2. 按资源类型定义复制语义

| 类型 | 复制什么 | 复制后归属/入口 | 使用前检查 | 不随复制获得 |
|---|---|---|---|---|
| 数字员工 | 允许分享的职责、提示配置、行为边界、资源依赖及发布版本内容 | 新个人Agent实例/副本，进入我的数字员工，保留来源版本和Lineage | 发布策略允许采用、个人使用权、节点候选资格、依赖和有效快照 | 原作者私人记忆、会话、任务文件、凭据、源编辑/发布权 |
| 技能 | 允许复制的技能定义、参数Schema、输入输出、资源包及依赖 | 我的技能中的独立副本/派生版本 | 内容校验、已有风险/发布规则、依赖及当前节点资格 | 未授权工具调用、源维护权、作者的执行环境秘密 |
| 工具/MCP | 允许分享的工具定义、动作Schema、非秘密参数和连接模板 | 我的工具/连接定义，来源可追溯 | 当前调用授权、合法连接身份、健康、节点动作范围 | 对方OAuth会话、Token、Secret、服务身份Grant或任意网络/目录权限 |

“加入使用”表示引用原发布版本及合法使用关系；“复制并使用”表示产生新的个人资源实例/副本和来源关系；“复制并编辑”表示新草稿及后续验证。三者由资源允许方式和主体授权决定，不能在后台悄悄把复制请求改成只读收藏。

原样复制是否可立即使用，依**现有允许派生采用的发布政策**和接收人的当前授权判断：内容摘要、版本、依赖及信任范围均满足时复用批准内容的既有合法采用路径；不能给未发布的新版本伪造“已发布”，也不能复制旧Grant或审批回执。若现有实现没有这种接通路径，就列为实现缺口，而非让普通员工误以为每次都要重新建资源或重复送审。

## 3. 权限与可用性矩阵

| 组合 | 员工看到什么 | 能做什么 |
|---|---|---|
| 无浏览权/无对象可见权 | 入口隐藏或合法空范围；深链接不泄漏存在性 | 无法检索/读取/复制 |
| 可查看，不可复制 | 获准详情与用途 | 查看；仅在政策明确允许申请时出现精确申请入口 |
| 可复制，当前不可运行 | 复制按钮、明确缺项 | 建立个人副本；补连接、缺依赖、发布或精确使用授权 |
| 可复制且可用于当前节点 | 复制并使用及依赖摘要 | 直接创建/复用本次幂等结果，加入本人资源并选择到节点 |
| 可引用使用，不可派生复制 | 加入使用，说明源版本 | 引用获准版本；不能伪装为个人可编辑副本 |
| 可编辑自己的副本 | 本人编辑、版本与发布入口 | 修改副本并重新验证；源资产和他人副本不变 |
| 市场维护者/领域管理员 | 自己领域的发布、版本、范围和健康 | 治理被授权资源；不自动读取员工私人业务 |

角色名称不直接决定上述组合；生产端按当前主体、资源关系、发布范围、动作、用途与节点资格计算allowedActions/字段投影。列表、详情、搜索、分类计数、推荐、下载、事件、缓存和深链接使用同一授权集合。客户端只能减少展示，不能成为真正授权边界。

## 4. 复制流程与状态

1. 目录读取已发布资源的授权投影；按类型走各自领域策略。
2. 点击复制时重查来源版本、允许采用方式、当前用户复制权及目标空间。
3. 检查最小依赖闭包，展示哪些已可用、哪些需要本人配置；私有依赖不能导出进复制包。
4. 使用idempotencyKey和请求摘要建立LocalCopy/领域资源及Lineage；依赖安装仍走对应类型的受控机制。
5. 计算个人可用状态，再计算当前节点可用状态；两者可能不同。
6. 成功后跳转本人资源详情或回原节点选中副本；按已有Assignment/快照启动。
7. 失败/超时保留采用记录，按同一意图查询或恢复，不能重复创建副本或重复外部副作用。

采用操作状态与资源就绪状态分别记录：
- 操作：pending / completed / failed / result_unknown，表示复制是否形成确定结果。
- 就绪：READY / NEEDS_AUTHORIZATION / NEEDS_CONFIGURATION / NEEDS_PUBLICATION / INCOMPATIBLE / WITHDRAWN。
- 节点适用性：合格/不合格及本人可见原因，随使用点重判。

READY只表示当前检查范围内可选用，不证明已装载、已运行或已交付。资源被下架不自动删除个人副本；若是安全撤销或原授权失效，必须阻止后续不合法使用并保留历史证据。

## 8. 与153项需求的完整映射

### MC-01 员工市场入口与三类资源发现

作为业务员工，我要从工作区或配置面板进入市场，按数字员工、技能、工具及业务用途筛选。

- Given：已有市场浏览权与对应资源可见范围。
- When：打开市场、切换类型、搜索并返回原工作。
- Then：仅展示有权查看的条目、字段与统计，保留任务定位和筛选；主执行人与协作人均可从自己的工作进入。
- 原需求关联：AG-05、SK-01、CN-03、WD-02；页面P22/P04/P05/P06/P07；流程F13；接口A17。

### MC-02 列表、详情与动作分别按权限投影

作为员工，我要知道资源是否可查看、复制、编辑和使用。

- Given：同一资源对不同用户的授权不同。
- When：查看列表/详情或打开资源深链接。
- Then：无权对象不泄漏名称或计数；可看不可复制者仍可读获准详情；伪造复制请求仍被服务端拒绝。
- 原需求关联：AD-01、AD-04、AG-02；页面P22/P04/P05/P06/P07；流程F13；接口A17。

### MC-03 复制到我的资源并直接选用

作为员工，我要把获准复制的数字员工、技能、工具变成自己的资源并用于当前节点。

- Given：发布版本允许复制使用，当前主体权限和依赖均满足。
- When：点击复制并使用。
- Then：创建有来源的新个人资源实例；加入对应我的目录并进入本节点选择；无需重复申请已有权限，也不自动开始运行。
- 原需求关联：AG-07、SK-01、CN-03、NC-02；页面P22/P04/P05/P06/P07；流程F13；接口A17。

### MC-04 原样复制、引用使用与编辑派生

作为资源使用者，我要明确副本、共享引用及编辑后版本的区别。

- Given：资源声明允许的采用方式。
- When：选择原样复制、加入使用或复制编辑。
- Then：复制记录新ID和来源；引用仍指向原发布版；编辑派生进入草稿/测试/发布流程，不修改源或冒用源批准。
- 原需求关联：AG-02、AG-07、SK-06；页面P22/P04/P05/P06/P07；流程F13；接口A17。

### MC-05 复制范围与私人信息隔离

作为员工，我要复用资源功能并使用自己合法的连接身份。

- Given：资源包含依赖、外部动作或私有数据引用。
- When：执行复制并查看复制结果。
- Then：不复制作者凭据、私人记忆、对话、业务文件或不可分享授权；缺连接时显示待配置而非可运行。
- 原需求关联：CN-04、CN-05、MM-01、HC-03；页面P22/P04/P05/P06/P07；流程F13；接口A17。

### MC-06 依赖与节点资格检查

作为节点执行人，我要确认复制资源是否真正适用。

- Given：资源具有技能/工具/知识依赖与发布/健康条件。
- When：复制预检并将副本配置到节点。
- Then：按类型检查最小依赖、版本、当前授权、发布、健康和节点资格；齐备可直接用，缺项分别给授权/配置/兼容/发布恢复入口。
- 原需求关联：NC-04、NC-07、CN-02、SK-03；页面P22/P04/P05/P06/P07；流程F13；接口A17。

### MC-07 来源、版本与升级影响

作为副本维护者，我要查看来源和新版差异并决定升级。

- Given：已经存在个人副本且源发布新版本或下架。
- When：查看来源、Diff和受影响任务。
- Then：来源版本固定；更新不静默覆盖个人修改或在途快照；下架按原因区分禁止新复制、撤权、风险停用及历史保留。
- 原需求关联：AG-04、SK-06、AD-08、NC-08；页面P22/P04/P05/P06/P07；流程F13；接口A17。

### MC-08 复制幂等与中断恢复

作为员工，我要在双击、断线和失败后找到确定的复制结果。

- Given：复制命令已提交但界面未收到明确结果。
- When：同键重试或查询采用记录。
- Then：同一意图只生成一个有效副本；显式再复制使用新意图；缺依赖/部分结果可恢复且不能误标全部成功。
- 原需求关联：AG-07、CN-08、OP-02；页面P22/P04/P05/P06/P07；流程F13；接口A17。

### MC-09 员工自助使用与市场治理

作为资源维护者，我要维护发布范围与版本；作为员工，我要自助使用已批准且获准的资源。

- Given：发布、可见范围、复制和使用政策明确。
- When：维护者发布/调整范围，员工浏览与采用。
- Then：员工看发现/复制/配置，维护者看自己的发布和依赖，管理员按领域治理；不要求每次合法复制都重复审批，不生成万能管理员。
- 原需求关联：AD-04、AG-06、SK-04、CN-09；页面P22/P04/P05/P06/P07；流程F13；接口A17。

### MC-10 市场副本回到本人节点并保持协作隔离

作为协作人，我要把市场副本用于自己的分工，同时保留主任务的共同上下文。

- Given：主执行人与协作人各有工作项及授权基线。
- When：双方分别复制、配置并执行。
- Then：各自Assignment不被覆盖；个人副本加入本人资源；共享业务基线一致，私人上下文隔离，旧版本提交仍受守卫约束。
- 原需求关联：NC-03、HC-08、CX-07、SY-03；页面P22/P04/P05/P06/P07；流程F13；接口A17。
