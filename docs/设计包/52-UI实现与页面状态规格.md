# UI实现与页面状态规格

开发文档包0.1｜`UI_SPEC / NOT_IMPLEMENTED`。视觉与业务原型以[31号](31-完整产品交互原型.html)设计1.3和34/35号为参考；原型为虚构内存演示。本文件规定如何使用底座组件和低代码配置落地，不把截图当成产品验收。

## 1. 信息架构和组件复用

顶层保持“工作、数字员工、能力与资源、管理”四区，按职责投影菜单。22个页面/内嵌视图保留；P03/P04/P09/P10/P12/P13/P20等优先任务或资源内抽屉/标签，不新增冗长导航层级。不同职责控制动作与内容，不复制整套应用。

优先底座现有Layout、Router、Permission、Table、Form、Drawer、Tabs、Upload、Dialog、Tree、Chart和通知组件。列表筛选、列配置、表单字段、图表、详情布局由已有Schema/设计器配置。只定制工作上下文容器、鱼骨路径、受限投影、版本差异和异步操作状态这些明确差异。

| 组件 | 绑定 | 交互/责任 |
|---|---|---|
| WorkContext | WorkCard + 主体/租户/工作/轮次 | 全任务唯一上下文键，切换隔离草稿和请求 |
| ConversationPane | ThreadEntry、明确的用户输入 | 只展示获准历史/摘要；不承载后台原始上下文 |
| WorkspaceStage | PathNode / ArtifactCard / 版本资源视图 | 右侧大展示区，切换路径/文档/文件夹/历史 |
| WorkActionBar | allowedActions + 操作状态 | 一个首要动作；保存与开始分开 |
| BindingDrawer | C04/C05/C27 | 推荐默认、差异预览、单项采用/撤销 |
| AsyncOperationCard | Operation / AttemptView | 受理、运行、未知、失败、恢复区分 |
| VersionPanel | VersionedRef + 获准源版本 | 比较、过期、重新核对；不篡改历史 |

组件注册表是受控模块/SPI，低代码配置只能引用已注册组件和动作ID，不允许任意HTML/JS/SQL、未审核远程脚本或私有数据表达式。

## 2. P02任务执行工作台

默认桌面左侧对话占约30%，右侧展示约70%；可拖动分隔条，左侧建议最小300px，右侧保持主要区域。任务标题、当前责任、状态和首要动作固定在顶部。展示区有“执行路径、文档、文件夹、历史摘要”四种模式，切换不创建新会话或重新执行任务。

```text
┌ 当前工作 / 实例标识 / 本人职责 / 状态 ────────── 当前首要动作 ┐
│ 对话（约30%）       │ 展示区（约70%）                        │
│ 获准历史与摘要       │ 路径 | 文档 | 文件夹 | 历史            │
│ 阶段/问题/建议       │                                      │
│                    │ 主流程 ── 节点 ── 当前节点 ── 接手     │
│                    │          ╱产物     ╲获准历史摘要       │
│ 输入与附件           │ 节点详情、成果版本或文档大预览          │
└───────────────────┴──────────────────────────────────────┘
```

鱼骨主干表达业务执行路径，分支表达已获准发现的节点产物、子工作、审核和历史摘要。它是流程事实投影，不是第二个执行器。节点点击只选择展示内容；执行、重试、审核、交付仍走显式命令。当前、完成、受阻、未知状态同时有文字和图形，不只靠颜色。

**权限细节**：有路径权无内容权显示通用受限节点及允许公开的阶段；不显示真实标题、附件名、对话摘要或工具名。连路径也无权时节点及相关计数不返回，UI不能预加载隐藏内容后遮罩。后台执行用权不会改变人端投影。改角色/任职/来源授权后重新取得投影，原响应代次失效。

## 3. 响应式、键盘和草稿

| 尺寸 | 行为 |
|---|---|
| ≥1280 | 同时双栏；鱼骨可缩放/水平平移；文档为主要区域 |
| 768—1279 | 可折叠对话侧栏；优先显示当前展示内容；表格允许受控横向滚动 |
| <768 | 对话/展示切换单栏；保留当前节点/文件位置；鱼骨提供可访问的阶段列表替代 |

分隔条可键盘调整，Tab顺序为任务摘要→对话→展示导航→展示内容→动作区。对话流更新不抢焦点，关键状态用适当live region提示。抽屉打开移入焦点，关闭回触发位置；错误关联字段，loading禁止重复提交。触控目标建议不小于44px；长标题换行/省略且可访问完整获准内容。

草稿按tenant + subject + work + responsibilityEpoch + draftKind分键；敏感正文不默认落localStorage。可恢复草稿使用服务端本人权限存储；撤权后不可继续读取。切换实例保留各自合法草稿，关闭旧请求和订阅；浏览器后退恢复位置但仍重验权限。草稿保存成功与任务提交成功分别提示。

## 4. 统一页面状态

| 状态 | UI呈现 | 可用动作 |
|---|---|---|
| LOADING | 保持布局骨架，隐藏未知权限动作 | 取消导航或等候，不重复写 |
| READY | 展示有依据的状态/版本/数据 | 当前allowedActions中的动作 |
| EMPTY_AUTHORIZED | 明确“当前范围暂无数据”，有获准入口 | 发起/导入等仅当服务端允许 |
| ERROR | 真实失败原因和requestId | 只读重试、必要恢复 |
| FORBIDDEN_OR_NOT_FOUND | 不存在/不可访问统一说明 | 返回获准列表；不透出对象名称 |
| STALE | 标出版本变化、保留合法草稿 | 回读差异、重新核对 |
| OFFLINE | 断网提示与最后状态时间 | 编辑合法本地草稿；写操作不得显示成功 |
| UNKNOWN_EFFECT | 原动作结果待查证 | 查询/有权恢复；禁止自动重发 |

服务端返回allowedActions是展示提示，实际调用仍重新鉴权。客户端不能把任意数组为空解释为无权限，也不能把403/503转成普通空态。

## 6. 全产品AI体验与低代码操作

| 场景 | 默认体验 | 按需展开 | 必须可撤销/恢复 |
|---|---|---|---|
| 本次配置 | 任务推荐、使用原因、缺项、开始前预览 | 可替换资源、预算解释 | 单项采用；并发时显示差异，不覆盖新值 |
| 数字员工/技能 | 用途卡、示例、可用动作、精确版本 | 维护者编辑输入输出Schema与依赖 | 草稿/测试/发布提案分开；停用查依赖 |
| 连接工具 | 选应用→选动作→原生授权→任务可用检查 | 身份范围、到期、诊断 | 已连接≠任务可用；重授权/取消 |
| 知识/本体 | 来源卡、版本、加工状态、引用和相关对象 | 有权者看关系争议/确认记录 | 撤权/来源更新后失效，不能自动确认事实 |
| 分析 | 自然语言问题→口径/范围预览→图表与明细 | 粒度/时区/过滤、来源版本 | 无样本为“—”，无权/失败各自提示 |
| 主动AI | 需要我处理的建议卡：原因、影响、下一步 | 冷却/期限；管理者才调组织限额 | 接受/忽略/稍后；接受先进入原任务草稿 |
| 进化 | 改进提案、版本差异、真实证据与试用结果 | 评估集/成本/策略指纹 | 未评测不发布；回退影响未来默认 |

对于熟悉业务的员工，尽量复用任务内配置和上下文，不另开“AI管理台”才能完成日常工作。管理员的配置页面也先推荐、检查、预览影响，再应用；复杂策略仍有访问入口但不强制首次学习。

## 7. 前后端绑定与验收

页面不得直接访问对象存储、模型或数据库；只消费获准DTO和受限版本文件接口。普通列表/表单从合同生成字段类型，跨字段业务规则仍服务端负责。SSE事件只更新失效标记或重取快照，不能直接触发C06/C11。异步结果的状态和文件引用经实际查询回读。

验收至少覆盖：390/768/1024/1440、键盘/焦点/长标题、双实例切换、草稿恢复、断线重连、受限路径、撤权晚到、文件解析失败、未知写效果、必需附件不可读、真零/无样本、配置撤销冲突。截图须同时关联真实Network响应、数据版本和已选源码；原31号截图只能校验设计表达。
