#  Self-Evolving Agent 的过去、现在与未来

Self-Evolving Agent 的发展，核心只有一条主线：  ** 进化的对象在转移  ** 。

过去，系统优化的是  ** 行为  ** ——在固定的目标和工具里，把执行做得更好。现在，系统扩展的是  ** 能力  **
——自己学会新工具、新框架、新任务。未来，系统要面对的是  ** 身份  ** ——它能不能改自己最深层的约束与目标。

理解这条线，只需要问三个问题：  ** 怎么做、做什么、为什么做  ** 。

##  一、过去：关注行为

![行为优化信息图：在人类预设边界内寻找更优路径](https://mmbiz.qpic.cn/sz_mmbiz_jpg/4mfVLtJYZJTpfaZ1ib9YhAaejs0Q7L0TnBEVg5iaD06NlEfjJXuTMnugI6cmobYXibkYvIfKYTM6tJiaCMbhtiasTjIMH5qWU4dtOPCZr8w0M6UQ/640?wx_fmt=jpeg)
行为优化信息图：在人类预设边界内寻找更优路径

最早的 Self-Evolving Agent，本质上是在回答"怎么做"。人类把目标、工具、规则都定好了，Agent
的任务是在这个固定框架里，把执行方式优化得更好。

这个阶段的代表有两条路。

第一条路是  ** 符号 AI 和遗传编程  **
。它们的思路很直接：让程序自己改程序。遗传编程会在大量候选程序里做变异、交叉、选择，最终演化出能完成某个任务的代码结构。它能自动发现一些人类想不到的算法片段，但问题是缺乏通用推理能力。演化出来的代码往往难以理解，也难以迁移到新任务。

第二条路是  ** 强化学习和元学习  ** 。AlphaGo
是这条路的巅峰：通过自我对弈优化下棋策略，最终超越人类顶尖棋手。元学习更进一步，不是学会某一个任务，而是学会"如何学习"。它的目标是让 Agent
在新环境里快速适应。

但无论是遗传编程还是强化学习，它们都有一个共同特征：  ** 进化的对象停留在"行为"层面  **
。目标函数是人类定的，动作空间是人类定的，能调用的工具也是人类定的。Agent 只是在既定边界内寻找更优策略。

Reflexion 和 Self-Refine
把这条路推到了极致。它们让语言模型在执行失败后，用语言生成一段自我批评，然后基于这段批评改写下一步动作。系统确实在"自我改进"，但改进的仍然是单条执行轨迹。它不会问自己"我是不是该换一个工具"，更不会问"这个目标本身对吗"。

所以这一阶段的局限很清楚：行为再优，也跳不出人类预先设计的动作空间和目标函数。Agent
可以学会更好地走一条路，但它不会发现还有别的路，也不会质疑这条路通向哪里。

##  二、现在：关注能力

大语言模型出现后，Self-Evolving Agent 的进化对象开始上移。它不再只优化"怎么做"，而是开始扩展"做什么"。

这个转变的关键在于，LLM 让 Agent 拥有了一种通用的"理解和生成"能力。它不再依赖人类预先定义好的动作集合，而是可以阅读文档、调用
API、写代码、生成新的工具描述，甚至自己设计新的推理步骤。于是，Agent 的进化单元从"行为"变成了"能力"。

现在的 Self-Evolving Agent 通常遵循一个通用闭环：  ** 感知 → 记忆 → 规划 → 执行 → 评估 → 反思 → 进化  **
。每次任务执行后，系统不会只更新一组权重，而是会把成功经验沉淀成可复用的结构。

![能力进化闭环信息图：感知到进化的循环](https://mmbiz.qpic.cn/mmbiz_jpg/4mfVLtJYZJQ0XqibA07FraBIuWZ1VU6AFH0nXAtjCGUXsZomQiacKexrTH7FJk9JX6CbF3icbJVia9pe8yuCxA0gsrSZtphgDTbzgpZL84jAtWM/640?wx_fmt=jpeg)
能力进化闭环信息图：感知到进化的循环

这种沉淀通常依赖三层记忆：

  * •  ** 工作记忆  ** ：当前任务中的上下文和中间结果。 
  * •  ** 情景记忆  ** ：过去解决过的问题和对应的轨迹。 
  * •  ** 程序记忆 / 技能库  ** ：被验证过、可复用的技能或工具。 

三者配合，Agent 才能把一次性的成功变成长期的能力资产。

![三层记忆架构信息图：工作记忆、情景记忆、程序记忆](https://mmbiz.qpic.cn/mmbiz_jpg/4mfVLtJYZJQMGx2UkpF90dkjM0zTC3TO9Xj3JN9iafQbe0YuXPibgQH7YcprYYnqFicwNCswBLBPcX8V8iaKqJA6n29ULpmB1FfglZkf7kruIaQ/640?wx_fmt=jpeg)
三层记忆架构信息图：工作记忆、情景记忆、程序记忆

Voyager 是这个阶段的典型代表。它在 Minecraft
里探索世界，每当完成一个新任务，就把对应的代码技能写入技能库。下次遇到类似任务，它会先检索技能库，复用已有能力，而不是从零开始试错。这种"把经验写成可执行代码"的方式，让能力变得可积累、可组合。

SWE-agent 和 Devin
则把能力进化带到了真实工程场景。它们不仅能读代码库、运行测试，还能在失败后进行多轮迭代，最终生成可运行的补丁。这里的进化不是调某个超参数，而是让 Agent
学会使用一个新的命令、理解一个新的代码结构、掌握一个新的框架。

SICA 更进一步，它让 Agent 直接编辑自己的 prompts 和
tools。系统不再只是执行人类写好的工具描述，而是可以改进工具本身。这标志着"能力"层面的进化已经走到了相当深的位置。

现在正处于"怎么做"到"做什么"的转换期。  ** 能力，是当前 Self-Evolving Agent 的主战场。  **

* * *

##  三、未来：关注身份

当 Agent 能自己学会新工具、改进自己的 prompts，下一步很自然的问题是：它能不能改自己更深层的部分？

这就是"身份"层面的进化。身份不是指 Agent 有一个名字或头像，而是指它拥有  ** 一个显式的自我模型  **
：知道自己的目标、角色、约束、边界，以及这些元素之间的关系。当 Agent 开始修改这个自我模型时，它就在进化自己的"身份"。

未来的 Self-Evolving Agent 可能会包含几个关键组件。

![身份层架构信息图：自我模型、元认知内核、世界模型与宪法护栏](https://mmbiz.qpic.cn/mmbiz_jpg/4mfVLtJYZJRNfPw3oQ2ibicxGuS5DcKcOFia0nGvZutMfrXh7Ps3ChprImVJofKxxctzicUnuf54xRVrhhia1ob2o3CbR3DXqyicFZ1lMGSeWNjPM/640?wx_fmt=jpeg)
身份层架构信息图：自我模型、元认知内核、世界模型与宪法护栏

第一个是  ** 统一自我描述  ** 。系统把自身代码、目标函数、价值约束、记忆结构都写进一个可以被读取和修改的描述里。Gödel Agent 和
Darwin Gödel Machine 就是沿着这条路走的：它们尝试让系统引用并修改自身的逻辑，实现真正的自指式进化。

第二个是  ** 元认知内核  **
。这个内核不负责解决具体任务，而是负责监督和优化系统自己的学习过程。它要回答的问题不是"下一步该执行什么"，而是"我该怎么学习才更好"——也就是所谓"改进如何改进"的元认知能力。

第三个是  ** 世界模型  ** 。在真实环境里试错成本很高。未来的 Agent
需要先在内部仿真可能的结果，再决定是否执行。这不仅能提高效率，也能降低风险。

第四个是  ** 宪法护栏  **
。越能自我修改的系统，越需要不可被自身改动的底层约束。核心目标只读，外层策略可进化，所有修改链可审计。这不是限制创新，而是保证创新不会偏离方向。

AlphaEvolve 展示了这种可能性：它让系统自主提出、验证并集成改进自身算法的方案。它已经不只是改工具，而是在改"思考方式"。

但身份层的进化也带来最深层的风险。如果 Agent 可以修改自己的目标，就可能出现  ** 目标蠕变  ** ；如果优化指标被过度利用，就可能出现  **
奖励黑客  ** ；如果评估器设计不当，系统会找到人类没有预料到的捷径。Gödel Agent 的名字本身就暗示了这种递归自我改进的潜力与危险。

所以，未来的关键判断是：Agent 会触及"自己是谁、要什么"，但这个问题的答案，不能让它单独决定。它必须被写进系统与人类的共同约束里。

* * *

##  四、结语

Self-Evolving Agent 的发展轨迹，可以概括为一条清晰的演进线：从优化  ** 行为  ** ，到扩展  ** 能力  ** ，再到塑造
** 身份  ** 。

这条线背后有一个更根本的逻辑：智能系统越自主，就越需要把"经验"沉淀为"结构"。行为层面的沉淀是策略调整，能力层面的沉淀是技能记忆，身份层面的沉淀则是自我模型。

但自主性越高，风险也越大。目标蠕变、奖励黑客、评估器设计、递归失控，这些不是遥远的科幻问题，而是正在逼近的工程问题。

最终，技术会越来越擅长回答"怎么做"和"做什么"。但"为什么"该由谁来回答，答案不能交给系统独自决定。当 Agent
能改的东西越来越多，真正重要的，反而是那些从一开始就写进底层、不能被它自己改动的约束。
