QoderWake 1.0.0

QoderWake 1.0 正式发布

今天，QoderWake 1.0 正式发布。从桌面里的 Agent，到工作现场的数字员工，QoderWake 1.0 提供了一套进入企业真实工作现场的 Agent 工作方式：在合适的时机主动开工，并让每一次执行都可查看、可追踪、可持续优化。你可以创建一个能理解角色和目标的 Waker，在对话、IM 群聊和自动任务中与它持续协作，再用 WakerFlow 编排多步骤工作。

创建属于你的 Waker

  • 支持通过自然语言描述自动生成自定义角色，并保存为模板。

在 IM 中随时协作

  • 通过 @Waker 将 Waker 接入钉钉、飞书等 IM，在群聊或单聊中响应工作请求。
  • 统一管理 IM 连接、聊天配对、响应 Waker、工作目录和启停状态，并可从配对详情查看任务记录与相关配置。
  • 优化消息排队、插话、中断与恢复体验，长任务执行期间也能继续补充要求。

组建 Waker 群组，协同完成复杂任务

  • 支持将多个本机或远程 Waker 加入同一个 Waker 群组，由默认负责人接收任务，也可以通过 @ 指定成员参与。
  • 可为每位成员独立配置模型和工作目录，并通过群技能与协作 SOP 明确分工和协作方式。
  • Waker 群组内可持续创建和切换任务，统一查看成员执行进度，以及按成员和共享空间归集的任务产物。

让工作自动发生

  • 新增统一的「自主工作」工作台，可通过定时、事件或 API 自动唤起 Waker 或 WakerFlow。
  • 支持集中查看、筛选、启停、复制和管理开工规则，并在详情页追踪运行历史。
  • 新增统一任务看板，以列表或泳道查看对话、群聊、WakerFlow 和自动任务的执行状态。

用 WakerFlow 编排复杂流程

  • 通过自然语言生成可运行的 WakerFlow，把复杂工作拆成多个步骤并交给不同 Waker 协作完成。
  • 支持手动运行，以及定时、事件和 API 触发；执行记录中可查看各节点的输入、思考、工具调用、输出和错误。
  • 支持版本历史与回滚，并可根据最近一次运行结果继续对话优化流程。

能力、资源、记忆与学习

  • 新增统一的「能力与资源」中心，集中管理技能、连接器、知识库、WakerFlow 和公开项目。
  • 支持从技能与连接器市场发现能力，并按需安装、授权和启用到 Waker。
  • 单个 Waker 新增「记忆与学习」入口，可查看全局记忆、记忆时间线，并管理自进化技能。
  • 优化知识库的创建、绑定、分享与资料管理，让团队知识更容易被 Waker 使用。

体验与稳定性改进

  • 完善亮色、暗色和窄窗口体验，并优化 Waker、WakerFlow、资源中心和任务看板的交互细节。
  • 提升长对话加载、启动恢复、任务状态同步和任务看板首屏性能。
  • 修复 IM 配对重复保存、专家协助回流、话题回复错位、自动任务漏跑、WakerFlow 导入与编辑、未读状态同步等问题。
  • 加强权限、认证、错误提示与运行可靠性治理，让失败原因更清晰，恢复路径更明确。
  • 改进慢速网络下的安装与更新，并增强 Windows 安装和热更新链路的稳定性。
感谢每一位参与体验和反馈的用户。QoderWake 1.0 是正式起点，我们会持续探索数字员工进入真实工作现场自主学习和工作，继续围绕更可靠的自主工作、更自然的人机协作和更开放的能力生态持续迭代。

QoderWake 是一款 AI 数字员工运行时平台，可以让你在本机组建一支"数字员工"团队（Wakers）。每个员工有岗位、有名字、有人设、有专长，可以被你召唤聊天或干活， 此次公测为Beta版本，支持 macOS（13+）、主流 Linux系统，暂未开放Window版本。

数字员工

  • 创建多个员工，每个拥有独立身份、记忆、技能和工作空间
  • 内置多种角色模板（软件工程师、QA、产品经理、数据分析师、内容运营专员等），也支持完全自定义角色
  • 通过自然语言对话直接派发任务，实时查看思考过程、代码产出和工具调用
  • 员工执行敏感操作前会主动征求同意，支持三档权限策略（允许/询问/禁止）

自动化触发器

  • 支持定时、GitHub Webhook 等多种触发方式
  • 提供运行历史、日历视图、月度统计、执行次数限制等管理能力
  • 支持保存前"测试拉取"，只读验证数据源连通性

Skill 与工具集成

  • 内置技能开箱可用，技能市场一键安装，也支持上传自定义技能包及自动沉淀skill

  • 工具级别精细开关控制

长期记忆

  • 跨会话持久化记忆，按板块组织（用户偏好、项目知识、关键决策等）
  • 支持个人记忆和项目级共享记忆
