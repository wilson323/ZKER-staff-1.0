# OA数字员工协作平台

独立项目目录：`/Users/mac/Documents/OA数字员工协作平台`。

产品目标：基于成熟 OA 工作流连接人、任务与交付，由承担人配置自己的数字员工，形成职责明确、权限可控、上下文一致的人与数字员工协作平台。

当前状态：**设计资料已入库；产品 OA 底座按 37/60 验证中（未终选）；M0 工程门禁已启动（NestJS + Vue3）。**  
Owner 已全权授权 Agent；裁决见 [docs/agent-decisions-m0.md](docs/agent-decisions-m0.md)、[docs/product-requirements-alignment.md](docs/product-requirements-alignment.md)。

当前完整设计1.3：保留153项原需求，补充12项全产品AI体验需求；覆盖21领域、22页面、41角色视角和72个待执行产品验收场景。设计以“工作、数字员工、能力与资源、管理”四个区域组织入口，按职责呈现，默认推荐配置，复杂选项按需展开。QoderWake与StaffDeck研究、来源和能力边界见33号文件。

最新补充：[任务执行工作台与通用权限设计](docs/设计包/34-任务执行工作台与权限分层设计.md)。任务内采用左对话、右侧鱼骨路径/文档/文件夹/历史摘要；八项EW细化分别约束路径可见、内容及摘要可读、后台可用、结果可发布和撤权恢复。商务/研发只是案例。
